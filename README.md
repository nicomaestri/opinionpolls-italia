# Opinion Polls Italia 🇮🇹

An interactive, data-driven dashboard for monitoring and analysing Italian political opinion polls.

The platform collects publicly available polling data and provides statistical tools to explore voting intention trends, uncertainty, and differences across polling institutes.

### Main Features

- **Latest Polling Average:** Smoothed estimates of party support using LOWESS regression.
- **Historical Trends:** Interactive visualisation of voting intention over time.
- **Confidence Intervals:** Statistical uncertainty associated with polling estimates.
- **Polling House Effects:** Analysis of systematic differences between polling institutes.
- **Polling Variability:** Comparison of estimates across institutes.
- **Party Correlations:** Correlation matrix of voting intention estimates.
- **Coalition Simulator:** Customisable electoral coalitions with aggregated polling support.

### Data Source
Publicly available Italian opinion polling data, primarily sourced from Wikipedia.

### Methodology
The dashboard applies statistical smoothing, descriptive analysis, and regression-based techniques to provide a transparent and reproducible interpretation of political polling data.
